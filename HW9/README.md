# ДЗ 9. Сериализация. Потоки. Чтение-запись

В исходном PDF указано «Домашнее задание 9», хотя имя файла начинается с `hw8`.

Для запуска нужен .NET SDK 8.0 или новее. Команды выполняются из папки `HW9`.

## Теоретические задачи

Ответы на задачи 1-3: [Answers.md](Answers.md).

## Задача 4

```console
dotnet run --project Task4
```

Создаёт персонажа с тремя предметами, выводит JSON с отступами, восстанавливает объект и показывает имя и количество предметов.

## Задача 5

```console
dotnet run --project Task5
```

Сохраняет персонажа в `save.json`, читает файл и выводит все данные загруженного персонажа. Файл создаётся рядом со скомпилированным приложением, например в `Task5/bin/Debug/net8.0`, независимо от текущей рабочей папки.

## Задача 6

```console
dotnet run --project Task6
```

При первом запуске запрашивает имя игрока, сложность от 1 до 3 и громкость от 0 до 100. Пустое имя и неверные числа нужно ввести повторно. Настройки сохраняются в `settings.json` рядом со скомпилированным приложением.

При следующем запуске программа читает настройки и выводит их без повторного ввода. Чтобы проверить первый запуск ещё раз, можно удалить созданный `settings.json`.

Некорректный JSON, неверные значения в сохранении и ошибки доступа к файлу сопровождаются сообщением. Существующий файл при этом не перезаписывается.
