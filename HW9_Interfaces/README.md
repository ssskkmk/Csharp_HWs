# Интерфейсы и инверсия зависимостей

Теория и ответ на вопрос к задаче 2.3: [Answers.md](Answers.md).

Для запуска нужен .NET SDK 8.0 или новее. Команды выполняются из папки `HW9_Interfaces`.

| Задача | Запуск |
| --- | --- |
| 2.1. Бой рыцаря и мага | `dotnet run --project Task2_1` |
| 2.2. Игровые предметы | `dotnet run --project Task2_2` |
| 2.3. Расчёт урона | `dotnet run --project Task2_3` |

Сборка всех проектов: `dotnet build Interfaces.sln`.

В задаче 2.3 один и тот же юнит перед каждым сравнением получает 200 HP. Сначала расчёты выполняются с бронёй 40, затем без брони. В формулах используется целочисленное деление; сначала применяется минимум 1, затем удвоение магического урона или бонус огня.
